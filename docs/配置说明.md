# 配置说明

README 里是部署的主线步骤，这里补充每一项具体怎么配，以及调试用的接口。测试环境：AstrBot v4.29.3、NapCat Windows Shell（QQNT 9.9.33）、Windows 10、RTX 5060。

## 1. NapCat

- 第一次用 `napcat.bat` 扫码登录小号，之后用 `napcat.quick.bat` 快速登录。
- 快速登录失效（日志里出现"登录已失效"）时，重新用 `napcat.bat` 扫一次码。
- 网络配置 → WebSocket 客户端：URL `ws://127.0.0.1:6199/ws`，消息格式 array，Token 和 AstrBot 平台适配器保持一致。
- 想把下线原因记下来，可以在 NapCat WebUI → 系统配置里打开文件日志。

## 2. AstrBot

### 2.1 平台适配器

| 字段 | 值 |
|---|---|
| ID | `qq_xiaohao`（插件里写死了这个 ID） |
| 类型 | aiocqhttp（OneBot v11） |
| 反向 WebSocket | `127.0.0.1` : `6199` |
| Token | 和 NapCat 里填的一样 |

### 2.2 模型提供商

| ID（示例） | 类型 | 用途 |
|---|---|---|
| `deepseek/...` | OpenAI 兼容，`https://api.deepseek.com/v1` | 聊天；群聊图片转述也可以用它 |
| `volc_xiaohe` | 火山引擎豆包语音（新版 V3 / API Key），由 `volc_tts` 注册 | 文字转语音 |
| `rvc_myvoice` | RVC 音色（底层 TTS + 本地变声），由 `rvc_voice` 注册 | 文字转语音。字段：`base_provider_id`（底层 TTS 的 ID）、`voice`（`cover/voices/` 下的文件夹名）、`pitch`（升降半音，默认 0）、`index_rate`（默认 0.5） |
| `local_sensevoice` | 本地 SenseVoice 语音识别，由 `rvc_voice` 注册 | 语音转文字 |

插件注册的提供商类型，要等插件装好、重载以后才会出现在新建列表里。

### 2.3 两个配置文件

在「配置」页顶部切换。新建一个"群聊"配置文件，在配置路由里把 `qq_xiaohao:GroupMessage:` 指向它，其余消息走 default。

| 设置 | default（私聊） | 群聊 |
|---|---|---|
| 人格 | 私聊人设（示例 `private_friend`） | 群聊人设（示例 `group_friend`） |
| 分段回复 | 开；正则 `.*?[。？！~…]+\|.+$`；间隔随机 `1.5,3.5` 秒 | 同左 |
| 文字转语音 | 开，概率 0.2 | 关（由 `voice_on_demand` 插件按需发） |
| 语音转文字 | 开，`local_sensevoice` | 开，`local_sensevoice` |
| 群聊上下文感知 | — | 开，最多 50 条；图片转述开 |
| 显示发言人昵称 / 群名 | — | 开 |
| 主动回复 | — | 关 |
| 白名单 | 开 | 开（两个配置文件填一样的列表） |
| 管理员 ID | `astrbot` + 你的大号 QQ | 同左 |
| 唤醒前缀 | `/` | `/` |

白名单格式：群用 `qq_xiaohao:GroupMessage:群号`（或直接写群号）；私聊必须写完整的 `qq_xiaohao:FriendMessage:QQ号`。

### 2.4 人格

`personas/` 里是两份示例。人格只开放 `search_memes` 工具时，机器人只会用表情包工具，不会去调用其他工具。

### 2.5 插件

| 插件 | 要改的地方 |
|---|---|
| meme_manager（插件市场） | 表情包概率 100、每条最多 1 张（什么时候发由 meme_gate 决定）；自动收集可以只收集你大号发的（`user:你的QQ`） |
| meme_gate | 无。对方发了表情包，或者消息里有"表情 / 斗图"，才放行表情包 |
| voice_on_demand | `VOICE_OWNER_IDS`；`GROUP_ANYONE`、`GROUP_MAX_CHARS`、`TRIGGER_WORDS` |
| volc_tts | API Key 放 `data/plugin_data/volc_tts/api_key.txt` |
| rvc_voice | `cover` 不和 `AstrBot` 文件夹并列时，设置环境变量 `QQBOT_COVER_DIR`；`ALIASES` 是 `/声音` 命令的中文别名 |
| ai_cover | 同上；`VOICE_NAME`（留空时自动使用 voices 里唯一的音色）、`CLIP_SECONDS`、`DAILY_LIMIT` |
| proactive_chat | `TARGETS`；时间段、最少沉默时长、每日上限、触发概率都在文件开头的设置区 |
| catch_up | 无 |

## 3. 翻唱和本地语音（cover/）

- `install_cover.bat`：自动找 conda（`CONDA_EXE` 环境变量 → PATH → 常见安装位置），在 `cover\Applio\env` 建 Python 3.12 环境，再安装 PyTorch 2.11（CUDA 12.8）、Applio 依赖和 audio-separator，下载基础模型和分离模型。下载缓存放在 `cover\.uv_cache`，装完自动清理。国内网络会自动切换清华、阿里云、hf-mirror 镜像。
- `install_stt.bat`：安装 FunASR，从 ModelScope 下载 SenseVoiceSmall。
- 混音音量在 `cover_job.py` 开头：`VOCAL_GAIN`、`INST_GAIN`、`BACKING_GAIN`。
- 升降调：只在"原调"和"升 / 降一个八度"之间选，哪个更接近音色的 `target_hz` 就选哪个，伴奏始终保持原调。默认女声 320 Hz、男声 160 Hz。
- 日志：`cover\logs\job_*.log`（每次翻唱一份）、`cover\logs\rvc_server.log`（本地语音服务）。

## 4. 调试接口

都需要 AstrBot 登录后的 `Authorization: Bearer <token>`，路径前缀是 `/api/v1/plugins/extensions`。

| 接口 | 作用 |
|---|---|
| `POST /ai_cover/test` `{"keyword": "成都 赵雷"}` | 只生成翻唱，不发 QQ；返回结果文件路径 |
| `POST /ai_cover/prefetch` | 提前下载所有分离模型 |
| `POST /ai_cover/fetch_voice` `{"name": "音色名", "urls": [...]}` | 从 HuggingFace 下载 `.pth` / `.index` 到 voices |
| `GET /proactive_chat/status`、`POST /proactive_chat/send_now` | 查看主动聊天状态 / 立即主动发一条 |
| `POST /volc_tts/preview` `{"speakers": [...], "text": "..."}` | 批量试听豆包音色 |
| `GET /catch_up/scan?since=<时间戳>`、`POST /catch_up/reply` | 查找并补回复掉线期间漏掉的消息 |
